# communicate —— 自研通信协议适配

> 入口：[`commen_readme.md`](../commen_readme.md) · 依赖台账：[`readme.md`](../readme.md)
> 分层：[`docs/layers/L1-drivers.md`](../docs/layers/L1-drivers.md) · 第三方驱动：[`drivers/readme.md`](../drivers/readme.md)

## 定位

**协议进，话题出；指令进，字节出。**
自己编写外部设备协议解析，把串口/TCP/UDP/CAN/Modbus/私有协议转换成 ROS 2 话题/服务/动作。

适用：无现成 ROS 2 驱动的 MCU、PLC、传感器、电源、升降机构、外部 IO；或已有驱动但需薄桥接。
不适用：已有成熟 ROS 2 驱动（→ `drivers/`）；纯算法/业务（→ 对应层）。

## 与 drivers 的分工

| | `drivers/` | `communicate/` |
| -- | ---------- | -------------- |
| 来源 | 下载第三方 | 本项目自研 |
| 内容 | 完整 ROS 2 驱动 | 传输 + 帧解析 + 话题转换 |
| 维护 | 跟随上游，尽量不改 | 自己维护/测试/演进 |
| 时机 | 已有 ROS 2 驱动 | 无驱动/私有协议/桥接 |

选择：有现成驱动 → `drivers/`；没有 → `communicate/`；桥接 → 薄封装并 `depend` 已有驱动，不复制代码。

## 做

- 传输管理：串口、TCP client/server、UDP、CAN（自定义）、Modbus RTU/TCP。
- 帧解析：帧头、长度、序号、CRC/checksum、转义、粘包/拆包、超时。
- 编解码：字节序、定点/浮点、位域、单位换算。
- 会话：心跳、超时、重连、请求-响应匹配、序号、重试、限流。
- ROS 转换：设备→话题；指令→设备帧。
- 诊断：连接状态、收发计数、校验错误、超时、设备错误码。
- 配置外置：端口、波特率、IP、设备 ID、超时、频率。
- 可测试：纯函数编解码、十六进制向量、mock 传输。

## 不做

- ❌ 任务决策/行为树（L5）。
- ❌ 运动规划/IK（L6）。
- ❌ 感知算法（L3）。
- ❌ UI/语音（L7）。
- ❌ 发布 `/control/*`；机械臂类设备只作为**订阅方**翻译 L6 指令。
- ❌ 协议结构体进 `interfaces/`；跨模块才进契约层。
- ❌ 业务参数（抓什么/放哪/速度策略）写进协议层。
- ❌ 向上层泄漏串口/帧格式；回调阻塞；静默丢帧。

## 输入 / 输出

输入：设备字节流；ROS 指令（话题/服务）；配置；节点时钟。
输出：ROS 话题（优先标准消息：`JointState/PoseStamped/TwistStamped/Imu/BatteryState`）、
服务/动作、设备字节流、`DiagnosticArray`。
所有输出带 `header.stamp`；需要坐标时带 `frame_id`；自定义接口走 `interfaces/` 流程。

## 目录

```
communicate/src/<device>_bridge/      # 一设备/协议一包
├── transport/                        # serial/tcp/udp/can 连接与收发
├── protocol/                         # 帧格式、编解码、校验、命令表
├── node.py                           # ROS 节点：话题 ↔ 协议
├── config/                           # 端口/IP/超时/频率
├── docs/protocol.md                  # 协议说明书（必须）
└── test/                             # 十六进制向量、mock 传输
```

## 关键约束

- 分层：`transport` 只收发字节；`protocol` 只编解码；`node` 只做 ROS 转换。
- 读线程/executor 独立，回调不阻塞；队列有界，溢出丢最旧并计数。
- 同一通道一个写者；多线程写需加锁/串行化。
- 时间戳取到达时刻；超时用单调时钟；心跳超时→离线/停发/诊断；重连退避。
- 错误：校验失败丢弃+计数+限流日志；帧不完整等待/超时丢弃；未知命令忽略；设备错误码翻译；
  断连停指令+重连；缓冲溢出告警；配置错误启动失败。
- 安全：指令可超时/停止；设备侧最好有独立看门狗；断连/故障进安全状态；不自动恢复危险动作。
- 可观测：诊断含连接/收发/帧数/校验错误/超时/最后错误；hex 日志仅 DEBUG+限流。

## 常见错误

| 错误 | 后果 | 正确 |
| ---- | ---- | ---- |
| 一次 read 当一帧 | 粘包/拆包错乱 | 帧头+长度+校验 |
| 不做校验 | 错帧当有效 | CRC/checksum + 丢弃计数 |
| 字节序假设错 | 数值错 | 文档写明 + 固定向量 |
| 回调 sleep/阻塞读 | executor 卡死 | 独立读线程 |
| 无超时/重连 | 断线假死 | 心跳+看门狗+退避 |
| 静默丢帧 | 上层无感 | 计数+诊断+限流日志 |
| 协议结构体进 interfaces | 契约污染 | 留在包内 |
| 一包对接所有设备 | 无法维护 | 一设备一包 |
