# L0 硬件层

> 索引：[`commen_readme.md`](../../commen_readme.md) · [`architecture.md`](../architecture.md)

## 定位

物理设备与安全回路。**没有业务代码**，但所有软件边界由它决定。

## 设备

| 设备 | 已知 | 状态 |
| ---- | ---- | ---- |
| AgileX 机械臂 | Piper / Piper_H / Piper_L / Piper_X / Nero | ✅ |
| 夹爪 `agx_gripper` | 开口 0–0.1 m，力 0.5–3.0 N | ✅ |
| 灵巧手 Revo2 / Pro / Touch | 左右手 | ✅ |
| CAN 模块 | `can0` 等 | ✅ |
| 相机、底盘、升降、急停 | 型号/接线待确认 | ⬜ |

## 职责

- 稳定供电、CAN/USB/网口物理链路。
- 硬件急停与断电，优先级高于任何软件。
- 机械安装、限位、负载在安全范围。
- 提供设备标识（CAN 口、序列号、左右手）供 L1 配置。

## 不做

- ❌ 任何 ROS 2 节点、launch、参数、算法。
- ❌ 用软件逻辑替代硬件急停。
- ❌ 在代码里补偿安装误差（必须标定）。

## 对软件的硬约束

| 约束 | 影响 |
| ---- | ---- |
| CAN 带宽有限 | 控制/反馈频率需权衡；避免多主抢总线 |
| 主从臂共 CAN | 必须人工指定 `fw_version` |
| 夹爪/手有量程与力限 | 上层不得超量程；L1 仍需限幅 |
| 急停=物理断电 | 恢复必须人工确认，禁止自动恢复 |
| 相机安装误差 | 必须标定消除 |

## 安全回路

`硬件急停 > 驱动看门狗 > 驱动限幅 > 运动校验 > 任务互锁 > 应用互锁`

## 验收

- L1 能稳定识别通信，断连可检测。
- 急停物理有效，恢复人工确认。
- 量程/速度/力限制有明确数值。
- 无硬件逻辑泄漏到 L3–L7。
