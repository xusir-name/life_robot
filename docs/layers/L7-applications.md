# L7 应用 / 交互层（Applications）

> 索引：[`commen_readme.md`](../../commen_readme.md) · **落地规范**：[`applications/readme.md`](../../applications/readme.md)

## 定位

人如何下达意图、看到状态、必要时接管。只做交互与展示，不负责机器人怎么动。

## 做

- 任务入口：CLI/UI/语音/按钮/远程 API，转成 L5 任务 action。
- 展示任务状态、进度、错误、场景快照、诊断。
- 遥操作入口（仅 `MANUAL`，经 L6）。
- 急停/暂停/恢复入口（急停优先硬件/驱动链路）。
- 权限与危险操作二次确认。
- 操作日志与任务历史。

## 不做

- ❌ 发 `/control/*`、直接控制硬件。
- ❌ 任务规划/行为树（L5）。
- ❌ 运动规划/IK/碰撞（L6）。
- ❌ 检测/位姿估计（L3）。
- ❌ 维护场景状态真源（L4）。
- ❌ 用 UI 逻辑替代 L1/L5/L6 的安全逻辑。

## IO

输入：人的指令、L5 状态/feedback/result、L4 场景（只读）、L1 状态（只读）、模式。
输出：L5 任务 action、取消/暂停、L6 遥操作（仅 MANUAL）、模式切换、展示/日志。

## 依赖

- 依赖：L5、L2、L4（只读）、L1（只读）、L6（仅 MANUAL）。
- 被依赖：无。
- 禁止：被低层依赖；L7 绕过 L5 改任务状态；发控制话题。

## 关键约束

- 只表达意图（如「抓杯子」），不表达关节角；位姿级操作仅遥操作/调试，经 L6 校验。
- **标定/调试类应用例外**：可在 `MANUAL`/离线模式调用运动接口（如 `/target_pose`），但不得发 `/control/*`；正式运行应经 L6 action。
- 危险动作二次确认；`AUTO` 只提交任务，`MANUAL` 允许遥操作，`ESTOP/FAULT` 禁止运动请求。
- 取消展示真实结果（`CANCELED`），不只改本地状态。
- UI 断线不能让机器人继续危险任务：L5 超时兜底。
- 展示数据来自 L5/L4/L1，不自行积分关节角、猜 TCP、维护物体列表。
- 高频可视化限流；操作日志可追溯（谁/何时/意图/结果）。

## 验收

- [ ] CLI/UI 可提交任务、看进度、取消、看到真实结果。
- [ ] `MANUAL` 遥操作可用，越权被拒。
- [ ] `ESTOP/FAULT` 下运动入口禁用并提示。
- [ ] 不发布 `/control/*`，不实现规划/感知。
- [ ] 操作日志可追溯；UI 断线不影响 L5 安全收敛。

## 仿真验证例外（临时）

- 为打通“检测框 → 抓取位姿 → 机械臂执行”链路，允许应用包内以**纯函数**实现抓取位姿估计，
  并通过仿真 `/target_pose` 桥接运动；实现与参数必须可单测、README 标注迁移目标。
- 仍**不得发布 `/control/*`**；真机前必须迁移到 L3（感知）与 L6（运动 action）。
- **临时例外**：`graspnet_pick` 的 `force` 模式可直接向 `/control/joint_states` 发送
  夹爪 `position` + `effort`，使用 AgileX 驱动内置力控；仅用于当前真机联调，正式运行必须迁到 L6。
- 当前实例：[`applications/src/graspnet_pick`](../../applications/src/graspnet_pick/README.md)。

## 越界

| 越界 | 正确 |
| ---- | ---- |
| UI 直接调 `/control/move_p` | 调 L5 任务或 L6 遥操作 |
| UI 自己维护物体位置 | 查 L4 |
| UI 写行为树 | L5 |
| UI 做碰撞检查 | L6 |
| 取消只改界面 | action cancel + 展示真实结果 |
| UI 替代急停 | 硬件急停 + L1 看门狗 + L5 仲裁 |
