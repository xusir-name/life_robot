# L4 世界模型层（World Model）

> 索引：[`commen_readme.md`](../../commen_readme.md) · [`architecture.md`](../architecture.md)
> **可按需引入**：出现多个消费方或需要物体生命周期时再落地。

## 定位

维护「机器人当前认为世界是什么样」的唯一可信状态：有哪些物体、在哪、什么状态、多久没更新。
是被动查询的知识库，不是调度中心。

## 做

- 订阅 L3 观测，做多帧融合、去重、跟踪、生命周期管理。
- 维护物体：ID、类别、位姿、尺寸、置信度、最后观测时间、状态。
- 维护场景：支撑面、可放置区域、障碍、机器人状态快照（只读）。
- 提供查询 service：按 ID/类别/区域/最近更新。
- 发布场景快照/增量；统一坐标表达（建议 `map`，无底盘用 `base_link`）。
- 健康诊断：融合延迟、物体数、过期比例。

## 不做

- ❌ 控制机器人、发 `/control/*`。
- ❌ 任务规划/行为树/技能调度。
- ❌ 检测/分割/位姿估计算法（L3）。
- ❌ IK/轨迹/导航规划。
- ❌ 拥有硬件状态（L1 所有，本层只读引用）。
- ❌ 改 L3 观测；不强制所有数据经过本层（L5 可只读 L1）。

## IO

输入：L3 观测（带 stamp/frame_id/confidence）、L1 状态快照（只读）、TF、标定/地图。

输出：

| 输出 | 形式 |
| ---- | ---- |
| 物体查询 | service：`get_object(id)`、`query_objects(class, region)` |
| 场景快照 | 低频 topic：全量物体 + 时间戳 |
| 场景增量 | topic：新增/更新/移除 |
| 可放置区域 | service/topic |
| 健康 | `diagnostic_msgs/DiagnosticArray` |

所有输出带 `header.stamp`/`frame_id`；物体必须有稳定 `id`。

## 依赖

- 依赖：L1（只读）、L2、L3、TF。
- 被依赖：L5（查询）、L6（只读障碍）、L7（只读展示）。
- 禁止：依赖 L5/L6/L7；主动调用 L6；写 L1/L3。

## 状态模型

| 字段 | 含义 |
| ---- | ---- |
| `id` | 稳定标识，融合后生成 |
| `class` | 类别 |
| `pose` | 统一坐标系位姿 |
| `size` | 包围盒（m） |
| `confidence` | 融合置信度 |
| `last_seen` | 最后观测时间 |
| `state` | `VISIBLE/OCCLUDED/LOST/REMOVED` |
| `source` | 来源观测/传感器 |

- 超时 → `OCCLUDED`；更久 → `LOST`；确认消失 → `REMOVED`。过期时间参数化，不同类别可不同。
- 禁止永久记忆；ID 不复用。

## 关键约束

- 写入只在本层；对外只读，查询返回快照+时间戳，调用方判断新鲜度。
- 多线程加锁或单线程事件循环；禁止跨线程共享可变状态。
- 观测进入时做一次坐标转换；TF 缺失则丢弃并上报，不存错误坐标系。

## 验收

- [ ] 物体列表稳定，跟踪期间 ID 不跳变。
- [ ] 查询返回位姿/置信度/最后观测/状态。
- [ ] 过期/丢失/移除策略可配置且有测试。
- [ ] 坐标系统一，TF 缺失有明确降级。
- [ ] 无控制发布、无任务决策。
- [ ] 健康诊断可见融合延迟与过期比例。

## 何时暂不引入

只有一个消费方（L5）、不需要跨帧记忆/多传感器融合/给 L6 障碍查询时，可先让 L5 直连 L3；
出现第二个消费方或生命周期需求时再引入，避免状态复制。
