# L5 决策 / 任务层（Decision）

> 索引：[`commen_readme.md`](../../commen_readme.md) · **落地规范**：[`decision/readme.md`](../../decision/readme.md)

## 定位

决定**做什么、按什么顺序做、失败怎么办**。用行为树把技能节点串联成任务。
不碰几何、硬件，只做任务编排与仲裁。

## 做

- 接收任务 action（`task_id/task_type/target/constraints/timeout/priority`）。
- 查询 L4 获取目标/区域；拆技能序列；调用 L6 action。
- 监控反馈，处理超时/取消/重试/降级/上报。
- 资源互斥（同一机械臂同一时间一个任务）。
- 安全仲裁：`AUTO/MANUAL/ESTOP/FAULT`，拒绝越权。
- 发布任务状态/进度/错误码；行为树可视化与测试。

## 不做

- ❌ IK/轨迹/碰撞几何（L6）。
- ❌ 发 `/control/*`、直接控制硬件。
- ❌ 检测/位姿/点云（L3）。
- ❌ 维护场景状态副本（查 L4）。
- ❌ 读驱动私有消息做业务判断。
- ❌ 底层限幅/看门狗（L1/L6）。
- ❌ 把业务算法藏进 Python `if/else`；流程必须在行为树里。

## IO

输入：任务 action、取消请求、L4 查询、L6 feedback/result、L1 只读状态、模式、配置。
输出：L6 action goal、任务状态/feedback/result、告警/诊断、模式状态。

长任务一律 action；必须带 `task_id`；错误枚举化，禁止只返回布尔。

## 依赖

- 依赖：L2、L4（查询）、L6（action）、L1（只读）、L8 配置。
- 被依赖：L7。
- 禁止：依赖 L3 内部；发 `/control/*`；写 L4。

## 任务契约

| 字段 | 含义 |
| ---- | ---- |
| `task_id` | 唯一，重复请求幂等 |
| `task_type` | `pick/place/pick_and_place/home` |
| `target` | 物体 ID 或位姿引用 |
| `destination` | 放置区域/位姿 |
| `constraints` | 速度/力/避让区域 |
| `timeout_s` | 整体超时 |
| `priority` | 抢占优先级 |

## 执行原则

- 幂等、可取消、可观测、有超时、失败收敛、资源互斥。
- 取消必须向下传 L6 并等待停止。
- 失败恢复：

| 失败 | 动作 |
| ---- | ---- |
| 未检测到目标 | 重新查询/观测，有限次数 |
| 不可达 | 调整预抓取位姿，有限重试 |
| 空抓/滑落 | 重试，N 次后上报 |
| 放置失败 | 重规划放置位姿，有限重试 |
| 碰撞/急停/硬件故障 | **禁止自动重试**，上报等人工 |
| 超时 | 取消当前动作，回安全位，上报 |

- `ESTOP/FAULT` 拒绝新任务；`MANUAL` 拒绝自动任务；模式切换记录日志与原因。
- 行为树节点只编排，不实现几何/感知；不直接拼 `/control/*`。

## 验收

- [ ] 任务 action 支持 goal/feedback/cancel/result，`task_id` 可关联。
- [ ] 「抓取-放置」端到端成功，失败有错误码与恢复/上报。
- [ ] 取消后下游停止，回到安全空闲。
- [ ] 并发任务被拒绝/排队，无双写。
- [ ] 模式约束生效。
- [ ] 无 `/control/*`、无 IK/轨迹代码。
- [ ] 任务状态可被 L7 订阅。

## 越界

| 越界 | 正确 |
| ---- | ---- |
| 直接发 `/control/move_p` | 调 L6 action |
| 自己算 IK | L6 |
| 缓存物体位姿长期使用 | 每次任务前查 L4，检查新鲜度 |
| 自己解析图像 | L3/L4 |
| 无限重试 | 有限次数 + 上报 |
| 取消只改本地标志 | 取消下游并等待停止 |
